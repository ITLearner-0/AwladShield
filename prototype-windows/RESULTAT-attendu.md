# Ce qu'il faut renvoyer

Après avoir lancé `Test-AwladCapture.ps1` :

1. Récupérez le fichier **`awlad-capture-report.txt`** (créé dans le même dossier
   que le script).
2. Relisez-le si vous voulez — il ne contient **aucun secret** (ni mot de passe,
   ni texte tapé, ni adresse complète).
3. **Renvoyez-le-moi** (copier-coller de son contenu, ou le fichier).

C'est tout. Pas besoin de remplir quoi que ce soit.

---

Si un test affiche « ERROR », ce n'est pas grave : c'est une information utile
(cela veut dire que cette capture-là ne marche pas telle quelle sur ce PC).
Recopiez simplement le message, il m'aide à adapter la suite.

Ne m'envoyez **pas** l'image `awlad-screenshot-sample.png` : elle montre votre
écran. Elle sert juste à vous prouver, à vous, que la capture d'écran a
fonctionné.
